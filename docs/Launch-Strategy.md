# Launch Strategy

---

# Objective

Validate product-market fit through controlled user testing before public launch.

---

# Phase 1

Private Alpha

Users

5

Audience

Friends and Product Managers.

Goal

Identify critical usability issues.

---

# Phase 2

Closed Beta

Users

25

Audience

PM interview candidates.

Goal

Validate AI feedback quality.

Metrics

- Interview completion
- Helpful feedback
- Session duration

---

# Phase 3

Public Beta

Users

100+

Goal

Collect qualitative feedback.

Measure

- User retention
- NPS
- Improvement rate

---

# Phase 4

General Availability

Goals

- Public website
- Authentication
- Analytics
- AI scaling

---

# Feedback Collection

Every user should answer:

- What worked?
- What confused you?
- Which feedback did you trust?
- Which feedback felt incorrect?
- Would you use this before a real interview?

---

# Success Criteria

Launch is considered successful when:

- Completion rate >80%
- Helpful feedback >90%
- Average improvement >15%
- NPS >50
