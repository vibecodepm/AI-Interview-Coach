# UX User Journey

---

# User Goal

Prepare for a Product Management interview efficiently with personalized AI coaching.

---

# Journey

```text
Landing Page

↓

Upload Resume

↓

Paste Job Description

↓

Select Target Role

↓

Start Interview

↓

Receive Question

↓

Submit Answer

↓

Receive AI Feedback

↓

View Improved Answer

↓

Continue Interview

↓

Receive Summary Report
```

---

# Emotional Journey

| Stage | Emotion |
|---------|----------|
| Landing | Curious |
| Upload Resume | Hopeful |
| First Question | Excited |
| AI Feedback | Nervous |
| Better Answer | Motivated |
| Final Report | Confident |

---

# Pain Points

- Resume upload failure
- Generic questions
- Slow responses
- AI hallucinations
- Feedback lacking explanation

---

# Opportunities

- Voice interviews
- Resume import from LinkedIn
- Company-specific interview packs
- Adaptive difficulty
- Personalized learning plans

---

# UX Principles

## Fast

Interview starts within two minutes.

---

## Personalized

Questions should feel unique.

---

## Transparent

Explain every score.

---

## Encouraging

Focus on coaching instead of criticism.
